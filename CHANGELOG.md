## [1.0.0] — 2026-01-01

### Added
- Stack detection for Python, Node.js, Go, Rust, Java, Ruby.
- Cloud provider support: AWS (ECS Fargate), GCP (Cloud Run), Azure (Container Instances).
- Terraform + Docker infrastructure generation.
- Monthly cost estimation.
- Interactive deployment preview with confirmation.
- CLI with detect, providers, preview, init, deploy commands.
